阅读指南

  1. 分别打开三个模型，先确认 Topic ID 与原模型一致。
  2. 观察 bubble 的面积，了解各 Topic 的相对 prevalence。
  3. 只在同一模型内观察圆的距离、邻近和重叠。
  4. 点击 Topic，先看 λ=1.0 的高概率词。
  5. 再看 λ≈0.6 和 λ≈0.2，比较区分度较高的词。
  6. 结合代表诗、既有语义审核和研究者标签理解；高相似只记为“建议人工复核”。
