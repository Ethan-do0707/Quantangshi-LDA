# 可复用模式

- 面向 LDA 的古诗分词采用“基础分词 + 确定性覆盖”，不要求重新训练模型即可修正高价值词界。
- 覆盖词典分开维护全局保护词、上下文命名实体和禁合并规则；人工裁决与硬边界优先，重叠时采用最长匹配。
- 典故表只负责提供候选和规范名映射；分词 token 保留原文字面，规范名与 `allusion_id` 通过旁表记录。
- 先识别保护短语，再删除停用词；否则会破坏含 `可`、`千` 等单字的固定表达。
- 长时间 LDA 实验按单模型保存参数签名、主题词/代表诗内容哈希和指标检查点；续跑前同时验证签名、文件存在与内容哈希，避免静默复用损坏输出。
- 断点续跑报告应分开记录全部模型拟合时间合计与当前命令墙钟时间；系统休眠会污染墙钟计时，但不应被误写为算法训练成本。
- 对既有建模产物制作人工审核包时，先建立字段级可用性矩阵：真实保存的数据原样呈现，缺失数据用状态、原因和空值表示；表头空表只能表示“结构预留但不可计算”，不能表示“零发现”。
- 人工评分模板必须把研究者输入与程序计算分开：初始标签和分数保持空白，只有在每项评分合法且完整时才汇总均值与低可解释性 Topic 数。
- 对随机算法做“精确复现”时，环境版本和指标近似一致仍不够；应重建原有格式化派生文件并比较整文件哈希，再持久化模型和矩阵并做回读相等检查。
- 密集概率矩阵必须与独立行列索引一起交付：Topic×Word 以 vocabulary term_index 对齐，Document×Topic 以 document matrix_row 对齐；元数据同时记录 shape、dtype、数组键和归一化口径。
- 跨不同词表的 Topic cosine 不得直接按列位置相乘；应在 token 并集上重新对齐。相似度阈值产生的是审核提示，阈值过宽时可能标记多数 Topic，不能替代人工可解释性判断。
