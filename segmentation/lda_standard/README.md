# 《全唐诗》LDA 分词规范（v1.0）

## 1. 适用范围与目标

本规范用于把《全唐诗》正文转换为 LDA 输入词序列。它约束的是最终研究口径，不把任何一种现成分词器的输出直接视为人工金标准。

默认实现口径为：

1. 以 `segmentation/results/sikufenci.jsonl` 为基础分词；
2. 在基础结果之上应用人工例外、命名实体、典故词和固定词词典；
3. 对剩余片段保留基础模型边界；
4. 分词完成后才删除标点和停用词。

之所以选 sikufenci 作为默认底稿，是因为当前停用词表及其统计均建立在该结果之上。若改用 Jiayan 或 jieba，也必须应用同一套保护词和禁合并规则，并另存口径，不得与 sikufenci 结果混用。

本规范采用“最小而稳定的语义单位”原则：既避免把 `来仪`、`折腰`、`倾城` 等切成单字，也避免把整句或自由组合过度粘连成稀疏长词。

## 2. 证据与限制

### 2.1 参考表的实际情况

`chuxueji_with_poem_example1.xlsx` 的 `Sheet1` 共 7,136 行，字段包括 `allusion_id`、`allusion_name`、`allusion_variants` 和 `poem_example` 等。

- `allusion_name` 有 6,824 个去重词形，长度主要为 2—4 字；其中仍有括号、书名号残片等非纯汉字数据。
- `allusion_variants` 按逗号、顿号、分号和换行初步切开后有 30,714 个条目、28,471 个去重词形。
- 原始异形中有 38 个单字项、103 个非纯汉字项，并混有“注”“关联意象”“常与……并提”“需结合语境”等解释性残片，最长条目达 25 字。

因此，`allusion_name` 和 `allusion_variants` 只能作为候选来源，禁止不经清洗和复核就全部导入强制合并词典。

## 3. 分词单位与输出要求

### 3.1 基本单位

- 输出 token 必须是原文中的连续字符片段。
- 所有 token 顺次拼接后必须严格还原原文；删除标点、停用词和异体归并应在另一步生成 LDA 视图。
- 不做繁简转换，不把异体字直接改写成通行字，不因词典中的规范词形而篡改原文。
- 典故异形可在旁表记录 `allusion_id` 和规范名，但正文 token 保留实际字面形式。

### 3.2 硬边界

下列位置绝不跨越合并：

- 句号、逗号、顿号、分号、冒号、问号、叹号；
- 引号、括号、书名号的边缘；
- 换行、题下注边界；
- `__` 等联句署名或数据库编辑标记。

标点和编辑标记可在 LDA 输入阶段删除，但必须先作为分词硬边界处理。

## 4. 决策优先级

同一位置出现冲突时，按以下顺序处理：

1. **原文硬边界**：任何词典都不得跨标点、换行或编辑标记。
2. **人工裁决**：经审校明确标为 `强制合并` 或 `强制切分` 的实例优先级最高。
3. **完整命名实体**：已登记的人名、地名、朝代年号、官署、宫殿、书名等采用最长匹配。
4. **已审核典故词**：只使用状态为 `KEEP_GLOBAL` 或 `KEEP_CONTEXT` 的典故词形。
5. **固定词和主题搭配**：使用 `protected_term_seed.tsv` 中的全局强制项。
6. **禁合并规则**：对未受前述词典保护的自由组合执行 `non_merge_rules.tsv`。
7. **基础分词器边界**：以上规则均未覆盖时，保留基础模型结果。

重叠词形采用“最长匹配”。同长度重叠时，人工裁决优先于实体，实体优先于典故，典故优先于一般固定词。词典中不得同时存在互相矛盾的合并与切分决策。

## 5. 必须合并的双音词和固定表达

完整的首批种子见 `protected_term_seed.tsv`。以下是必须执行的类别。

### 5.1 用户指定的最高优先级词形

以下六项无条件作为一个 token：

`来仪`、`折腰`、`倾城`、`难再逢`、`良可惜`、`千钟`。

它们只能保护自身，不得向左右任意扩张：

- `彩凤肃来仪` → `彩凤 / 肃 / 来仪`，不得合为 `彩凤肃来仪`；
- `安能摧眉折腰事权贵` → `安 / 能 / 摧眉 / 折腰 / 事 / 权贵`；
- `倾城独立世所稀` → `倾城 / 独立 / 世 / 所 / 稀`；
- `欢乐难再逢` → `欢乐 / 难再逢`；
- `芳辰良可惜` → `芳辰 / 良可惜`；
- `千钟圣酒` → `千钟 / 圣酒`。

### 5.2 联绵词、叠词和不可析固定词

双字拆开后不能保持原有词义、音韵功能或语法功能的词必须合并。例如：

`淹留`、`逍遥`、`徘徊`、`踌躇`、`参差`、`逶迤`、`蹀躞`、`依依`、`悠悠`、`翩翩`、`萧萧`、`袅袅`、`冉冉`、`霭霭`、`茫茫`、`漫漫`、`寂寂`、`冥冥`、`凄凄`、`皎皎`。

新收词必须能说明“拆分会破坏稳定词义”，不能只凭相邻频率高就纳入。

### 5.3 稳定诗歌意象和文化名物

在全唐诗中反复作为整体意象或名物使用的双音组合，默认合并。例如：

- 天时景物：`明月`、`白云`、`青云`、`浮云`、`烟霞`、`清风`、`春风`、`秋风`、`落日`、`夕阳`、`流水`、`落花`、`芳草`；
- 山水行旅：`青山`、`绿水`、`孤舟`、`扁舟`、`渔舟`、`征帆`、`长亭`、`故乡`、`边塞`、`关山`；
- 音乐礼制：`胡笳`、`羌笛`、`琵琶`、`琴瑟`、`宫商`、`金石`；
- 历史文化：`干戈`、`社稷`、`青史`、`丹青`、`凤阙`、`芳辰`、`寸阴`、`尺璧`。

这是版本化白名单，不推导出“所有颜色词＋名词”或“所有修饰语＋名词”都应合并。

### 5.4 已词汇化的数量、时空表达

以下已进入保护词表的形式合并：

`千钟`、`千秋`、`万古`、`百年`、`万里`、`千里`、`一生`、`三春`、`九重`。

未列入白名单的数量结构按普通句法切分，如 `一 / 杯`、`百 / 尺`、`千 / 山`、`万 / 树`。

## 6. 典故词保留规范

### 6.1 保留层级

典故词分成两层：

- `KEEP_GLOBAL`：词形本身已经稳定词汇化，全文出现时均合并，如 `来仪`、`折腰`、`倾城`、`千钟`、`杜宇`、`封侯`、`斑竹`、`湘妃`、`洛神`。
- `KEEP_CONTEXT`：词形可能有普通义，只有结合相邻词、人物或典故语境才能判定，如 `采薇`、`梦蝶`、`烂柯`、`乘槎`、`青眼`、`折桂`、`题柱`、`投笔`，以及部分简称、借代和地理异名。

未经人工复核的候选一律为 `PENDING`，不得进入正式 LDA 词典。

### 6.2 `allusion_name` 的准入条件

一个 `allusion_name` 进入保护词典，必须同时满足：

1. 去除首尾空白后为连续汉字；
2. 一般长度为 2—4 字；5 字以上须单独说明不可再分的理由；
3. 在全唐诗正文中有逐字连续命中；
4. `allusion_mean` 或 `source_text` 能支持其确为典故标签，而非普通句法片段；
5. 人工赋予 `KEEP_GLOBAL`、`KEEP_CONTEXT`、`SPLIT_INTERNAL` 或 `REJECT_NOISE` 之一。

### 6.3 `allusion_variants` 的准入条件

异形词必须先按 `,`、`，`、`、`、`;`、`；` 和换行拆项并清除首尾空格，然后逐项审核。以下项目直接排除：

- 单字异形；
- 含括号、引号、书名号、拉丁字母、数字或残缺标点的条目；
- 含“注”“关联”“常与……并提”“需结合语境”“本源不同”“变体相近”等解释文字的条目；
- 整句、整联或可正常拆成多个内容词的长片段；
- 在正文中从未逐字出现的词形。

2—4 字纯汉字异形也不自动通过；必须确认它是稳定典故变体，而不是参考表作者为解释关系临时写出的短语。

### 6.4 长典故的处理

- 2—4 字：优先作为 LDA 词项审核。
- 5—8 字：只有不可再分且在语料中有复现，或经研究者明确指定时，才可作为一个 token。
- 9 字以上：默认只做典故跨度标注，内部仍按本规范分词，不把整句压成一个低频 token。

### 6.5 可审计字段

正式典故词表至少保存：

`surface`、`canonical_allusion_name`、`allusion_id`、`source_column`、`decision`、`scope`、`review_reason`、`reviewer`、`version`。

同一典故的多个异形在分词层保留原字面形式；若 LDA 需要归并，可另加 `lemma` 层，但不得覆盖原始 token。

## 7. 人名保留规范

### 7.1 必须作为整体的人名

- 完整姓名、复姓姓名：如 `东方朔`；
- 约定俗成的字、号、别称：如 `仲尼`、`渊明`；
- 姓名或人物并称：如 `尧舜`、`尧禹`；
- 与人物绑定的固定称号：须以实体词典登记后采用最长匹配。

首批语料内已命中的人名见 `named_entity_seed.tsv`，包括 `孔子`、`仲尼`、`颜回`、`屈原`、`宋玉`、`贾谊`、`相如`、`文君`、`昭君`、`苏武`、`李陵`、`张骞`、`班超`、`东方朔`、`陶潜`、`渊明`、`谢安` 等。

### 7.2 人名歧义

`相如`、`文君`、`渊明` 等简称必须在实体语境中判定。出现下列证据之一可保留为人名：

- 与姓、官职、封号、人物事件或同一典故中的另一人物相邻；
- 参考表的 `source_text`、`allusion_mean` 或已审核异形明确指向该人物；
- 诗题、注释或上下句形成稳定人物指称。

不能因为两个汉字恰好与人名相同，就把普通句法用法强制标成人名。

## 8. 地名保留规范

### 8.1 必须作为整体的地名

- 城邑、州郡、区域：`长安`、`洛阳`、`咸阳`、`金陵`、`成都`、`扬州`、`江南`、`关中`、`陇西`、`西域`、`中原`；
- 关塞：`玉门关`、`阳关`、`函谷关`、`潼关`、`剑门`；
- 山川湖泽：`泰山`、`华山`、`嵩山`、`庐山`、`终南`、`昆仑`、`黄河`、`长江`、`湘江`、`渭水`、`洛水`、`洞庭`、`彭蠡`、`瞿塘`；
- 神话或典故地理：`扶桑`、`蓬莱`、`瀛洲`、`玄圃`、`瑶池`。

完整首批表见 `named_entity_seed.tsv`。

### 8.2 地名后接普通成分

只合并已登记的完整地名，不吞并普通后续成分：

- `长安城`：若词典只登记 `长安`，则为 `长安 / 城`；
- `洛阳道`：`洛阳 / 道`；
- `洞庭湖`：词典若已登记完整别名 `洞庭湖`，则采用最长匹配。

方位词或处所词不能自动吸附到前词；`山中`、`江上`、`月下` 一般按自由结构处理，而 `江南`、`关中`、`塞上` 等已登记地域词除外。

## 9. 不应该合并的词和结构

详见 `non_merge_rules.tsv`。核心原则如下。

### 9.1 不跨句法边界机械造词

若未被高优先级词典保护，下列结构默认保留内部边界：

- 否定、疑问、情态词＋谓词：`不 / 知`、`未 / 见`、`莫 / 问`；
- 介词或连词＋宾语：`与 / 君`、`于 / 兹`、`以 / 此`、`为 / 客`；
- 人称或指示成分＋谓词、名词：`我 / 欲`、`君 / 归`、`此 / 地`；
- 自由动宾结构：`登 / 楼`、`望 / 月`、`入 / 山`、`出 / 关`、`送 / 客`；
- 自由数量结构：`一 / 杯`、`百 / 尺`、`千 / 山`、`万 / 树`；
- 普通方位结构：`山 / 中`、`江 / 上`、`月 / 下`、`门 / 前`、`天 / 外`。

`折腰`、`采薇`、`投笔`、`封侯`、`千钟` 等白名单项优先于这些一般规则。

### 9.2 不把整句当词

参考表中的长异形、说明句和整句引用不能因“涉及同一典故”就合成一个 token。例如：

- `欢乐难再逢` 只保护 `难再逢`；
- `芳辰良可惜` 只保护 `良可惜`；
- `凤凰来仪` 若未作为完整已审核典故词登记，则至少保持 `凤凰 / 来仪`；
- `倾国倾城` 可在完整四字形式已审核时整体保留；否则仍须保证其中 `倾城` 不被拆开。

### 9.3 不以统计相关性代替词法判断

相邻互信息、词频或某一分词器的长词输出只能生成候选，不能直接决定合并。特别是颜色词＋名词、修饰语＋名词、动词＋宾语等结构，即使高频也要经过语义审核。

## 10. 推荐处理流程

1. 保存原文和字符偏移；建立不改写原文的工作副本。
2. 标记标点、换行和编辑符号硬边界。
3. 应用人工强制合并、强制切分实例。
4. 对命名实体做最长匹配，并处理歧义简称。
5. 对已审核典故词做最长匹配。
6. 应用固定词白名单和禁合并规则。
7. 对未覆盖片段保留基础分词器边界。
8. 验证全部 token 能逐字还原原文。
9. 另行删除标点和停用词；不得在短语识别前先删除 `可`、`千` 等单字。
10. 输出分词结果、词典版本、规则版本和审计日志。

## 11. 验收标准

每次词典或规则变更至少检查：

- `''.join(tokens) == 原文`；
- 六个指定表达在所有命中位置均为单一 token；
- 不跨标点、换行或 `__` 合并；
- 人地名按最长登记词形保留；
- 典故词表不存在 `PENDING`、单字噪声或解释性残片；
- `强制合并` 与 `强制切分` 无冲突；
- 统计合并前后 token 数、词型数、单字率和受影响诗歌数；
- 用相同 LDA 参数比较规则变更前后的主题稳定性，防止过度合并造成稀疏化。

## 12. 版本维护

- 本规范、保护词表、实体表和禁合并规则必须使用同一版本号。
- 新增词形须记录语料例句、来源、判定、理由和审核人。
- 删除或改判既有词形须保留变更记录，不得静默覆盖。
- 参考表不是金标准；与正文、上下文或人工裁决冲突时，以正文和可复核证据为准。

## 13. 当前实现与输出

执行：

```powershell
python segmentation/lda_standard/apply_standard.py
```

脚本保留原始 `sikufenci.jsonl`，另行生成：

- `segmentation/results/sikufenci_lda.jsonl`：应用本规范后的完整分词；
- `segmentation/results/sikufenci_lda.metadata.json`：规则版本、哈希、边界变更统计和验证结果；
- `segmentation/results/sikufenci_lda.audit.csv`：仅列出词界发生变化的诗歌及前后预览。

实现细则：

- `强制合并` 和 `条件保留` 词形都会保护其字面边界；条件项不自动赋予规范名、人物身份或典故语义。
- 需要词性或语境判断的禁合并类别，只执行 `non_merge_rules.tsv` 中明确写有斜线的实例；数量结构 R05 另对未受保护的前置数词串作通用切分。
- 默认拒绝覆盖已有派生结果；确需按新版规则重建时使用 `--overwrite`。
- 本次源结果与统一语料有 1 处字符差异：诗歌 ID 1 的 `sikufenci` 字符序列为“连甍”，`poems.jsonl` 为“连薨”。此次任务以待重新分词的 `sikufenci.jsonl` 字符序列为准，不静默修改统一语料；差异已写入元数据。
